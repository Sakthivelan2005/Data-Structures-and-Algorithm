# Hash Table

- **Hash Table** is Linear Data Structure.
- It is designed to store, read, and delete key-value pairs in O(1) average time complexity.


## Hash Function

- **Hash Function** acts like a translator, taking an input of any size (Key) and converting it into a fixed-size value (hash code) that can be used as an index within the hash table's internal array. 

- This process of mapping arbitary keys to fixed-length indices is called ***hashing***
